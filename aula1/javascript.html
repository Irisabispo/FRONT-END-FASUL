JavaScript

Fundamentos do JavaScript

JavaScript é uma linguagem de programação amplamente utilizada no desenvolvimento web. Compreender a sintaxe, a estrutura básica e os conceitos fundamentais do JavaScript é essencial para criar aplicações web dinâmicas e interativas.

Sintaxe e Estrutura Básica

A sintaxe do JavaScript é bastante semelhante a outras linguagens de programação, como C++ e Java. A estrutura básica de um programa JavaScript consiste em declarações, expressões e comentários.

  • Declarações: Instruções que executam ações, como declarar variáveis, criar funções e controlar o fluxo do programa.
  • Expressões: Combinações de valores, operadores e chamadas de função que produzem um resultado.
  • Comentários: Trechos de texto que não são executados pelo interpretador e servem para adicionar anotações e explicar o código.

Declarando Variáveis:

// Declaração de variável (var)
var nome = "João";

// Declaração com let (escopo de bloco)
let idade = 25;

// Constante (não pode ser reatribuída)
const PI = 3.14159;

// Tipos de dados
let numero = 42;          // Número
let texto = "Olá";        // String
let verdadeiro = true;    // Booleano
let lista = [1, 2, 3];    // Array
let objeto = {chave: "valor"}; // Objeto

Tipagem dinâmica: O JavaScript é uma linguagem de tipagem dinâmica, o que significa que não precisamos especificar o tipo de dado ao declarar uma variável.

Estruturas de Controle

As estruturas de controle no JavaScript permitem controlar o fluxo de execução do programa. Podemos utilizar estruturas condicionais, como if, else if e else, para executar blocos de código diferentes dependendo de uma condição. Também podemos utilizar loops, como for e while, para repetir um bloco de código várias vezes.

Condicionais e Loops:

// Estrutura condicional
let idade = 18;
if (idade >= 18) {
    console.log("Maior de idade");
} else {
    console.log("Menor de idade");
}

// Loop for
for (let i = 0; i < 5; i++) {
    console.log("Número: " + i);
}

// Loop while
let contador = 0;
while (contador < 3) {
    console.log("Contador: " + contador);
    contador++;
}

// Switch
let dia = "segunda";
switch (dia) {
    case "segunda":
        console.log("Início da semana");
        break;
    case "sexta":
        console.log("Fim da semana");
        break;
    default:
        console.log("Meio da semana");
}

Funções Embutidas

Além disso, o JavaScript possui uma variedade de funções embutidas que nos permitem realizar operações específicas. Por exemplo, a função alert() exibe uma caixa de diálogo com uma mensagem para o usuário, a função prompt() exibe uma caixa de diálogo para receber a entrada do usuário, e a função console.log() exibe uma mensagem no console do navegador.

alert()

alert("Mensagem de alerta!");
Exibe uma caixa de diálogo com uma mensagem

prompt()

let nome = prompt("Digite seu nome:");
Exibe uma caixa de diálogo para receber entrada

console.log()

console.log("Mensagem no console");
Exibe uma mensagem no console do navegador

typeof

typeof "texto"; // "string"
Retorna o tipo de um valor

Manipulação do DOM

Para interagir com elementos HTML, o JavaScript utiliza o Document Object Model (DOM). O DOM representa a estrutura do documento HTML como uma árvore de objetos, permitindo manipular os elementos, alterar seu conteúdo, estilo e comportamento.

Podemos selecionar elementos HTML usando métodos como getElementById(), getElementsByClassName() e querySelector(), e então aplicar mudanças usando propriedades e métodos do DOM.

Selecionando e Manipulando Elementos:

// Selecionar por ID
let titulo = document.getElementById("meuTitulo");
titulo.textContent = "Novo Título";
titulo.style.color = "blue";

// Selecionar por classe
let itens = document.getElementsByClassName("item");
for (let i = 0; i < itens.length; i++) {
    itens[i].style.backgroundColor = "lightgray";
}

// Selecionar com querySelector
let paragrafo = document.querySelector(".destaque");
paragrafo.innerHTML = "Conteúdo modificado";
paragrafo.classList.add("ativo");

// Criar novo elemento
let novoItem = document.createElement("li");
novoItem.textContent = "Novo item da lista";
document.querySelector("ul").appendChild(novoItem);

Programação Assíncrona

A programação assíncrona é uma parte fundamental do JavaScript. Podemos utilizar callbacks, promessas e a sintaxe async/await para lidar com operações assíncronas, como requisições AJAX, animações e manipulação de eventos.

Callbacks

Funções que são passadas como argumentos para outras funções, permitindo que sejam chamadas de volta quando um determinado evento ocorrer ou quando um processo assíncrono for concluído. 

function processar(callback) {
    setTimeout(() => {
        callback("Concluído!");
    }, 2000);
}

processar((mensagem) => {
    console.log(mensagem);
});

Promessas

Objetos que representam a eventual conclusão ou falha de uma operação assíncrona. Permitem encadear operações com then(). 

let promessa = new Promise((resolve, reject) => {
    let sucesso = true;
    if (sucesso) {
        resolve("Operação bem-sucedida!");
    } else {
        reject("Erro na operação");
    }
});

promessa
    .then(resultado => console.log(resultado))
    .catch(erro => console.log(erro));

Async/Await

Sintaxe que simplifica o código assíncrono, permitindo escrever operações assíncronas de forma mais concisa e legível, aguardando resultados com a palavra-chave await. 

async function buscarDados() {
    try {
        let resposta = await fetch("https://api.exemplo.com/dados");
        let dados = await resposta.json();
        console.log(dados);
        return dados;
    } catch (erro) {
        console.log("Erro na requisição:", erro);
    }
}

// Uso
buscarDados();

De modo geral, ao entender a sintaxe, a estrutura básica e os conceitos fundamentais do JavaScript, você estará preparado para utilizar essa linguagem de programação de forma efetiva no desenvolvimento de aplicações web. Com o JavaScript, é possível criar interações dinâmicas, manipular elementos HTML, controlar o fluxo do programa e lidar com operações assíncronas.

JavaScript em Aplicações Web

A capacidade de utilizar a linguagem de programação JavaScript de forma efetiva no desenvolvimento de aplicações web é essencial para criar sites e aplicações interativas, dinâmicas e responsivas.

Interação com o DOM

Por meio do JavaScript, podemos selecionar elementos HTML, manipular seus atributos, estilos e conteúdo, criar eventos e responder a interações dos usuários. Isso possibilita a criação de funcionalidades como botões de clique, menus deslizantes, validação de formulários, entre outros.

Criando Eventos:

// Botão de clique
document.getElementById("btn").onclick = function() {
    alert("Botão clicado!");
};

// Event listener (recomendado)
document.getElementById("btn").addEventListener("click", function() {
    console.log("Botão clicado com addEventListener");
});

// Menu deslizante
document.querySelector(".menu-toggle").addEventListener("click", function() {
    document.querySelector(".menu").classList.toggle("ativo");
});

// Evento de mouseover
document.querySelector(".card").addEventListener("mouseover", function() {
    this.style.transform = "scale(1.05)";
});

Validação de Formulários

Um exemplo prático de utilização do JavaScript é a validação de formulários em uma página web. Podemos utilizar eventos, como o evento de submissão de um formulário, para verificar se os campos foram preenchidos corretamente antes de enviar os dados ao servidor.

Validando um Formulário:

document.getElementById("form").onsubmit = function(event) {
    let nome = document.getElementById("nome").value;
    let email = document.getElementById("email").value;
    let senha = document.getElementById("senha").value;

    if (nome === "" || email === "" || senha === "") {
        alert("Preencha todos os campos!");
        event.preventDefault(); // Impede o envio
        return false;
    }

    if (!email.includes("@") || !email.includes(".")) {
        alert("E-mail inválido!");
        event.preventDefault();
        return false;
    }

    if (senha.length < 6) {
        alert("A senha deve ter pelo menos 6 caracteres!");
        event.preventDefault();
        return false;
    }

    alert("Formulário enviado com sucesso!");
};

Carrosséis e Slideshows

Outro exemplo é a criação de carrosséis ou slideshows em uma página web. Com JavaScript, podemos criar um carrossel de imagens que é capaz de exibir as imagens em sequência, com transições suaves e controles de navegação.

Criando um Carrossel de Imagens:

let imagens = ["img1.jpg", "img2.jpg", "img3.jpg", "img4.jpg"];
let indice = 0;

function mudarImagem(direcao) {
    indice += direcao;
    if (indice < 0) indice = imagens.length - 1;
    if (indice >= imagens.length) indice = 0;
    document.getElementById("slide").src = imagens[indice];
}

// Controles
document.getElementById("proximo").addEventListener("click", function() {
    mudarImagem(1);
});

document.getElementById("anterior").addEventListener("click", function() {
    mudarImagem(-1);
});

// Auto-play (troca a cada 3 segundos)
setInterval(function() {
    mudarImagem(1);
}, 3000);

Requisições Assíncronas (AJAX)

Além disso, o JavaScript permite a realização de requisições assíncronas ao servidor, o que possibilita a atualização de conteúdo de forma dinâmica, sem a necessidade de recarregar a página inteira.

Carregando Conteúdo Dinâmico:

// Usando Fetch API (moderno)
async function carregarPosts() {
    try {
        let resposta = await fetch("https://api.exemplo.com/posts");
        if (!resposta.ok) {
            throw new Error("Erro na requisição");
        }
        let dados = await resposta.json();

        let container = document.getElementById("posts");
        container.innerHTML = ""; // Limpa o conteúdo

        dados.forEach(post => {
            container.innerHTML += `
                <article class="post">
                    <h3>${post.titulo}</h3>
                    <p>${post.conteudo}</p>
                    <small>Publicado em: ${post.data}</small>
                </article>
            `;
        });
    } catch (erro) {
        console.log("Erro ao carregar:", erro);
    }
}

// Carregar ao rolar a página (infinite scroll)
let carregando = false;
window.onscroll = function() {
    if (carregando) return;
    if (window.innerHeight + window.scrollY >= document.body.offsetHeight - 200) {
        carregando = true;
        carregarPosts().finally(() => {
            carregando = false;
        });
    }
};

// XMLHttpRequest (tradicional)
function carregarDadosXML() {
    let xhr = new XMLHttpRequest();
    xhr.open("GET", "https://api.exemplo.com/dados");
    xhr.onreadystatechange = function() {
        if (xhr.readyState === 4 && xhr.status === 200) {
            let dados = JSON.parse(xhr.responseText);
            console.log(dados);
        }
    };
    xhr.send();
}
